# Learner License RTO Test

Static site for GitHub Pages. No build step.

## Publish
1. Create a GitHub repository and upload everything in this folder to the `main` branch.
2. Repository Settings > Pages > Build and deployment > Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.
3. Your site appears at `https://<username>.github.io/<repository>/` after a minute.

## Add the Android app link later
Open `index.html`, find `window.SITE={appUrl:""}` and put your link between the quotes.
The "Coming soon" button on the home screen then becomes a "Get it on Android" button.

## Note on copy protection
Selection, copy, right-click, drag, print and common developer shortcuts are blocked. This stops casual copying only.
Anything a browser can display can still be captured by screenshot or by reading the page source.
